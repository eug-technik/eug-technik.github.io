# EUG – Technik aus dem Spreewald

Öffentliche Landingpage für den geplanten Klimaanlagen-Wartungsservice von EUG.

Die Website wird über GitHub Pages veröffentlicht und ist unter [www.eug-service.de](https://www.eug-service.de/) erreichbar.

## Veröffentlichung

- Organisation: `eug-technik`
- Repository: `eug-technik.github.io`
- Hauptdatei: `index.html`
- Domain: `www.eug-service.de`

## Hinweise

Die Seite enthält eine Interessensabfrage. Impressum, Datenschutzangaben und die endgültigen Kontaktdaten werden vor dem öffentlichen Einsatz vollständig ergänzt.
